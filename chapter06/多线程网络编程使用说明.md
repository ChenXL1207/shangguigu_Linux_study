# 多线程网络编程使用说明

## 程序概述

本章节包含两个程序：
1. **multi_conn_threads_server.c** - 多线程服务器
2. **multi_conn_threads_client.c** - 多线程客户端

## 程序特点

### 服务器端特性
- 支持多个客户端同时连接
- 每个客户端使用独立线程处理
- 线程分离模式，自动回收资源
- 接收客户端消息并回复"收到"
- 监听端口：6666

### 客户端特性
- 双线程设计：读线程和写线程分离
- 支持同时发送和接收消息
- 优雅退出：使用 shutdown() 关闭写端
- 连接到本地服务器 127.0.0.1:6666

## 多客户端测试

### 测试场景

1. 启动一个服务器
2. 打开多个终端窗口，每个窗口启动一个客户端
3. 观察服务器如何处理多个并发连接

### 预期行为

- 每个客户端都获得一个独立的线程
- 所有客户端可以同时发送消息
- 服务器对每个客户端独立处理
- 线程通过 pthread_detach() 自动回收

## 关键技术点

### 1. 线程创建
```c
pthread_create(&pid_read, NULL, read_from_server, &client_socketfd)
```

### 2. 线程分离
```c
pthread_detach(pid_read);  // 服务器使用，自动回收资源
```

### 3. 线程等待
```c
pthread_join(pid_read, NULL);  // 客户端使用，等待线程结束
```

### 4. 优雅关闭
```c
shutdown(client_socketfd, SHUT_WR);  // 关闭写端
```

## 网络编程流程

### 服务器流程
1. 创建套接字 `socket()`
2. 绑定地址 `bind()`
3. 开始监听 `listen()`
4. 循环接受连接 `accept()`
5. 为每个连接创建线程 `pthread_create()`
6. 分离线程 `pthread_detach()`

### 客户端流程
1. 创建套接字 `socket()`
2. 连接服务器 `connect()`
3. 创建读线程 `pthread_create()`
4. 创建写线程 `pthread_create()`
5. 等待线程结束 `pthread_join()`
6. 关闭连接 `close()`

## 注意事项

1. **端口冲突**：确保端口 6666 未被占用
   ```bash
   netstat -tuln | grep 6666
   ```

2. **防火墙**：如果连接失败，检查防火墙设置

3. **内存管理**：
   - 每个线程独立分配缓冲区
   - 线程退出前必须释放内存
   - 使用 free() 释放 malloc() 分配的内存

4. **线程安全**：
   - 服务器中每个客户端有独立的套接字
   - 客户端读写使用不同的线程
   - 没有共享数据需要加锁

5. **错误处理**：
   - 所有系统调用都检查返回值
   - 使用 handle_error() 宏处理错误
   - 线程创建失败直接退出程序

## 常见问题

### Q1: 客户端连接被拒绝
**原因**：服务器未启动或端口错误
**解决**：检查服务器是否在 6666 端口监听

### Q2: 编译错误找不到 pthread
**原因**：未链接 pthread 库
**解决**：确保 makefile 正确配置了 -lpthread

### Q3: 服务器无法启动
**原因**：端口已被占用
**解决**：使用 `netstat` 查找占用进程并关闭

### Q4: 消息发送后无响应
**原因**：网络连接问题或服务器崩溃
**解决**：检查网络状态，查看服务器日志
