# socket_ipc_communication 测试指南

## 测试方法

这是一个 UNIX 域套接字通信程序，支持服务器和客户端模式。

### 方法一：使用两个终端窗口

#### 步骤 1：启动服务器
在第一个终端窗口中运行：
```bash
cd /home/xuanliang-chen/shangguigu_LInux/linux_shangguigu/chapter06
./build/socket_ipc_communication.out server
# 或者
./build/socket_ipc_communication.out
```

服务器会显示：
```
启动服务器
```

#### 步骤 2：启动客户端
在第二个终端窗口中运行：
```bash
cd /home/xuanliang-chen/shangguigu_LInux/linux_shangguigu/chapter06
./build/socket_ipc_communication.out client
```

客户端会显示：
```
连接服务器成功
```

#### 步骤 3：测试通信
在客户端终端中输入消息，例如：
```
Hello, Server!
```
按回车发送。

服务器会显示：
```
客户端连接成功，路径: unix_domain.socket
接收到客户端消息: Hello, Server!
```

客户端会显示：
```
接收到服务器消息: OK
```

#### 步骤 4：结束通信
在客户端终端中输入：
```
EOF
```
按回车，程序会结束。

#### 创建测试消息文件
```bash
cat > test_messages.txt << EOF
Hello, Server!
This is a test message
Testing UNIX domain socket
EOF
```

#### 启动服务器（后台运行）
```bash
./build/socket_ipc_communication.out server &
```

#### 使用文件作为输入
```bash
cat test_messages.txt | ./build/socket_ipc_communication.out client
```

## 常见问题

### 问题：bind: Address already in use
**原因**：之前的服务器进程还在运行，或者 socket 文件还存在。

**解决方法**：
```bash
# 清理 socket 文件
rm -f unix_domain.socket

# 或者查找并结束相关进程
ps aux | grep socket_ipc_communication
kill <进程ID>
```

### 问题：连接失败
**原因**：服务器未启动或 socket 文件不存在。

**解决方法**：确保先启动服务器，再启动客户端。

## 测试检查点

- [ ] 服务器能正常启动
- [ ] 客户端能成功连接到服务器
- [ ] 客户端发送消息，服务器能接收并回复 "OK"
- [ ] 客户端能接收服务器的回复
- [ ] 发送 "EOF" 后程序能正常退出
- [ ] 服务器和客户端都能正常清理资源
