6.1.1 按地理范围分类
1. 个人区域网 PAN (Personal Area Network)
   - 覆盖范围：10米以内
   - 典型技术：蓝牙、红外、ZigBee
   - 应用场景：手机与耳机连接、智能手表等

2. 局域网 LAN (Local Area Network)
   - 覆盖范围：几公里以内
   - 典型技术：以太网、WiFi、令牌环
   - 应用场景：家庭网络、办公室网络、校园网

3. 城域网 MAN (Metropolitan Area Network)
   - 覆盖范围：几十公里
   - 典型技术：光纤网络、ATM、FDDI
   - 应用场景：城市范围内的网络连接

4. 广域网 WAN (Wide Area Network)
   - 覆盖范围：几百公里到全球
   - 典型技术：互联网、帧中继、X.25
   - 应用场景：国际互联网、企业专网

6.1.2 按网络拓扑分类
1. 总线型拓扑网络结构
   - 特点：所有设备共享一条通信介质
   - 优点：结构简单，成本低
   - 缺点：单点故障影响整个网络，扩展性差
   - 典型应用：早期以太网

2. 星型拓扑网络结构
   - 特点：所有设备连接到中心节点（如交换机、集线器）
   - 优点：易于管理，单点故障不影响其他设备
   - 缺点：中心节点故障影响整个网络
   - 典型应用：现代以太网、WiFi网络

3. 网状拓扑网络结构
   - 特点：设备之间可以有多个连接路径
   - 优点：可靠性高，容错能力强
   - 缺点：成本高，结构复杂
   - 典型应用：互联网骨干网、军事网络

4. 环形拓扑网络结构
   - 特点：设备连接成环形，数据沿环传输
   - 优点：结构简单，传输延迟可预测
   - 缺点：单点故障影响整个网络
   - 典型应用：令牌环网络、FDDI

6.1.3 按传输介质分类
1. 有线网络
   - 双绞线：成本低，传输距离有限
   - 同轴电缆：抗干扰能力强，传输距离较远
   - 光纤：传输速度快，距离远，抗干扰能力强

2. 无线网络
   - 无线电波：WiFi、蓝牙、移动通信
   - 红外线：短距离通信
   - 微波：卫星通信、点对点通信

6.1.4 按网络所有权分类
1. 公用网：互联网、电信网络
2. 专用网：企业内网、政府专网
3. 虚拟专用网（VPN）：在公用网上建立的专用网络
