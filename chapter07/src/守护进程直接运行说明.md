# 守护进程直接运行说明

## 概述

守护进程服务器现在支持两种运行模式：
1. **前台模式**（默认）：显示交互信息，适合测试和调试
2. **守护进程模式**：后台运行，适合生产环境

## 使用方法

### 1. 前台模式运行（显示交互信息）

直接运行可执行文件，不加任何参数：

```bash
cd chapter07
./build/daemon_server.out
```

**输出示例：**
```
========================================
  守护进程服务器 (前台模式)
========================================
端口: 8888
PID: 12345
日志文件: /tmp/daemon_server.log
按 Ctrl+C 退出
========================================

[Mon Nov  7 22:00:00 2024] 服务器启动（前台模式）
✓ 服务器已启动，等待客户端连接...

[新连接] 客户端 127.0.0.1:54321 已连接
>>> 客户端 [127.0.0.1:54321] 发送消息: Hello Server
<<< 回复客户端: 收到消息
[连接关闭] 客户端 127.0.0.1:54321 已断开
```

### 2. 守护进程模式运行（后台运行）

使用 `-d` 或 `--daemon` 参数：

```bash
./build/daemon_server.out -d
```

或者：

```bash
./build/daemon_server.out --daemon
```

**特点：**
- 后台运行，不占用终端
- 输出只写入日志文件
- 自动创建PID文件

### 3. 指定端口运行

使用 `-p` 或 `--port` 参数指定端口：

```bash
# 前台模式，使用端口 9999
./build/daemon_server.out -p 9999

# 守护进程模式，使用端口 9999
./build/daemon_server.out -d -p 9999
```

### 4. 查看帮助信息

```bash
./build/daemon_server.out -h
```

或

```bash
./build/daemon_server.out --help
```

## 命令行参数

| 参数 | 长参数 | 说明 | 示例 |
|------|--------|------|------|
| `-d` | `--daemon` | 以守护进程模式运行 | `./daemon_server.out -d` |
| `-p PORT` | `--port PORT` | 指定端口号（1-65535） | `./daemon_server.out -p 9999` |
| `-h` | `--help` | 显示帮助信息 | `./daemon_server.out -h` |

## 使用示例

### 示例1：前台模式测试

**终端1 - 启动服务器：**
```bash
cd chapter07
./build/daemon_server.out
```

**终端2 - 运行客户端：**
```bash
cd chapter07
./build/daemon_client.out
```

然后输入消息，服务器会实时显示交互信息。

### 示例2：守护进程模式

**启动守护进程：**
```bash
cd chapter07
./build/daemon_server.out -d
```

**查看日志：**
```bash
tail -f /tmp/daemon_server.log
```

**查看PID：**
```bash
cat /tmp/daemon_server.pid
```

**停止守护进程：**
```bash
kill $(cat /tmp/daemon_server.pid)
```

### 示例3：使用自定义端口

```bash
# 服务器使用端口 9999
./build/daemon_server.out -p 9999

# 客户端连接时需要修改端口（修改 daemon_client.c 中的 PORT 定义）
```

## 前台模式 vs 守护进程模式

| 特性 | 前台模式 | 守护进程模式 |
|------|---------|-------------|
| 运行方式 | 占用终端 | 后台运行 |
| 输出 | 控制台 + 日志文件 | 仅日志文件 |
| 适用场景 | 测试、调试 | 生产环境 |
| 终端关闭 | 进程终止 | 继续运行 |
| PID文件 | 不创建 | 自动创建 |

## 交互显示内容

前台模式下，服务器会显示：

1. **启动信息**
   - 服务器标题
   - 端口号
   - 进程PID
   - 日志文件路径

2. **连接信息**
   - 客户端连接通知
   - 客户端IP和端口

3. **消息交互**
   - 收到的消息（`>>>` 表示接收）
   - 发送的回复（`<<<` 表示发送）

4. **断开信息**
   - 客户端断开连接通知

5. **退出信息**
   - 按 Ctrl+C 退出时的提示

## 注意事项

1. **端口占用**：如果端口已被占用，前台模式会显示错误信息，守护进程模式会记录到日志

2. **日志文件**：无论哪种模式，日志都会写入 `/tmp/daemon_server.log`

3. **PID文件**：只有守护进程模式才会创建 `/tmp/daemon_server.pid`

4. **信号处理**：
   - 前台模式：Ctrl+C 会显示退出提示
   - 守护进程模式：需要使用 `kill` 命令发送信号

5. **多实例运行**：可以同时运行多个实例，但需要使用不同的端口

## 常见问题

### Q: 如何切换到守护进程模式？

A: 使用 `-d` 参数：
```bash
./build/daemon_server.out -d
```

### Q: 如何查看守护进程的输出？

A: 查看日志文件：
```bash
tail -f /tmp/daemon_server.log
```

### Q: 如何停止守护进程？

A: 使用 kill 命令：
```bash
kill $(cat /tmp/daemon_server.pid)
```

### Q: 如何修改端口？

A: 使用 `-p` 参数：
```bash
./build/daemon_server.out -p 9999
```

### Q: 前台模式和守护进程模式可以同时运行吗？

A: 可以，但需要使用不同的端口：
```bash
# 终端1
./build/daemon_server.out -p 8888

# 终端2
./build/daemon_server.out -d -p 9999
```
