# 守护进程使用指南

## 文件说明

- `daemon_server.c` - 守护进程服务器程序源代码
- `daemon_client.c` - 客户端程序源代码
- `test_daemon.sh` - 守护进程测试和管理脚本
- `守护进程学习文档.md` - 详细的守护进程学习文档

## 快速开始

### 1. 编译程序

```bash
cd chapter06
make
```

编译后会生成：
- `build/daemon_server.out` - 守护进程服务器
- `build/daemon_client.out` - 客户端程序

### 2. 启动守护进程

**方法一：使用测试脚本（推荐）**

```bash
cd src
./test_daemon.sh start
```

**方法二：直接运行**

```bash
./build/daemon_server.out
```

### 3. 查看守护进程状态

```bash
cd src
./test_daemon.sh status
```

### 4. 测试守护进程

```bash
cd src
./test_daemon.sh test
```

或者在另一个终端手动运行客户端：

```bash
./build/daemon_client.out
```

### 5. 查看日志

```bash
cd src
# 查看完整日志
./test_daemon.sh log

# 实时查看日志
./test_daemon.sh log -f
```

或者直接查看日志文件：

```bash
cat /tmp/daemon_server.log
tail -f /tmp/daemon_server.log
```

### 6. 停止守护进程

```bash
cd src
./test_daemon.sh stop
```

## 测试脚本使用说明

`test_daemon.sh` 提供了完整的守护进程管理功能：

```bash
./test_daemon.sh {start|stop|status|test|restart|reload|log}
```

### 命令说明

- `start` - 启动守护进程
- `stop` - 停止守护进程
- `status` - 查看守护进程状态和日志
- `test` - 运行客户端测试守护进程
- `restart` - 重启守护进程
- `reload` - 重新加载配置（发送 SIGHUP 信号）
- `log` - 查看日志文件（可使用 `-f` 参数实时查看）

## 手动管理守护进程

### 查看进程

```bash
# 查看PID文件
cat /tmp/daemon_server.pid

# 查看进程信息
ps aux | grep daemon_server

# 查看进程树
pstree -p $(cat /tmp/daemon_server.pid)
```

### 发送信号

```bash
# 发送 SIGTERM 信号（正常退出）
kill -TERM $(cat /tmp/daemon_server.pid)

# 发送 SIGHUP 信号（重新加载配置）
kill -HUP $(cat /tmp/daemon_server.pid)

# 发送 SIGINT 信号（中断）
kill -INT $(cat /tmp/daemon_server.pid)

# 强制终止（不推荐）
kill -9 $(cat /tmp/daemon_server.pid)
```

## 验证守护进程特性

### 1. 验证后台运行

启动守护进程后，即使关闭终端，守护进程仍然继续运行。

### 2. 验证独立于终端

```bash
# 启动守护进程
./build/daemon_server.out

# 关闭终端，守护进程仍然运行
# 在新终端中查看
ps aux | grep daemon_server
```

### 3. 验证日志记录

守护进程的所有输出都记录在日志文件中，而不是终端。

```bash
tail -f /tmp/daemon_server.log
```

### 4. 验证信号处理

```bash
# 发送 SIGTERM 信号
kill -TERM $(cat /tmp/daemon_server.pid)

# 查看日志，应该看到退出消息
tail /tmp/daemon_server.log
```

## 常见问题

### 1. 端口被占用

如果端口 8888 已被占用，可以修改 `daemon_server.c` 中的 `PORT` 定义：

```c
#define PORT 8888  // 改为其他端口
```

### 2. 权限问题

如果无法创建 PID 文件或日志文件，检查 `/tmp` 目录的权限：

```bash
ls -ld /tmp
```

### 3. 守护进程无法启动

检查是否有其他实例在运行：

```bash
ps aux | grep daemon_server
```

如果存在，先停止：

```bash
./test_daemon.sh stop
```

### 4. 客户端无法连接

- 检查守护进程是否运行：`./test_daemon.sh status`
- 检查端口是否监听：`netstat -tlnp | grep 8888`
- 检查防火墙设置

## 注意事项

1. 守护进程以 root 用户或普通用户运行，注意权限问题
2. 日志文件会不断增长，需要定期清理或使用日志轮转
3. PID 文件在进程异常退出时可能不会自动删除，需要手动清理
4. 生产环境中应该使用 systemd 等系统服务管理器管理守护进程
