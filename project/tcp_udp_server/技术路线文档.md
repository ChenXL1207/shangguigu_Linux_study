# TCP/UDP 回声服务器技术路线文档

## 📋 项目概述

### 项目目标

开发一个同时支持 TCP 和 UDP 协议的回声服务器（Echo Server），能够：
- 接收客户端发送的数据
- 将数据原样返回给客户端
- 支持多个客户端同时连接（TCP）
- 支持并发处理（UDP）
- 提供清晰的日志输出

### 回声服务器特点

- **TCP 回声服务器**：面向连接，可靠传输，支持多客户端
- **UDP 回声服务器**：无连接，快速响应，支持广播

## 💻 实现方案

### 方案一：TCP 回声服务器（多线程）

#### 设计思路

```
主线程：监听连接
    ↓
接受连接 → 创建子线程
    ↓
子线程：处理客户端通信
    ↓
接收数据 → 回显数据 → 关闭连接
```

#### 核心代码结构

```c
// 主线程
while (1) {
    clientfd = accept(serverfd, ...);
    pthread_create(&tid, NULL, handle_tcp_client, &clientfd);
}

// 处理线程
void *handle_tcp_client(void *arg) {
    int clientfd = *(int *)arg;
    char buffer[BUFFER_SIZE];
    
    while (1) {
        ssize_t n = recv(clientfd, buffer, sizeof(buffer), 0);
        if (n <= 0) break;
        
        // 回显数据
        send(clientfd, buffer, n, 0);
    }
    
    close(clientfd);
    return NULL;
}
```

#### 关键技术点

1. **线程创建**：使用 `pthread_create()` 为每个客户端创建线程
2. **线程分离**：使用 `pthread_detach()` 自动回收线程资源
3. **数据回显**：接收多少数据，就发送多少数据
4. **连接管理**：正确处理客户端断开连接

### 方案二：UDP 回声服务器（单线程）

#### 设计思路

```
主循环：
    ↓
接收数据（recvfrom）→ 获取客户端地址
    ↓
回显数据（sendto）→ 使用客户端地址
    ↓
继续循环
```

#### 核心代码结构

```c
while (1) {
    struct sockaddr_in client_addr;
    socklen_t client_len = sizeof(client_addr);
    
    // 接收数据
    ssize_t n = recvfrom(udpfd, buffer, sizeof(buffer), 0,
                        (struct sockaddr *)&client_addr, &client_len);
    
    if (n > 0) {
        // 回显数据
        sendto(udpfd, buffer, n, 0,
              (struct sockaddr *)&client_addr, client_len);
    }
}
```

#### 关键技术点

1. **无连接特性**：UDP 不需要建立连接
2. **地址管理**：每次通信都需要客户端地址
3. **数据报边界**：UDP 保持数据报边界
4. **错误处理**：处理网络错误和数据丢失

### 方案三：统一服务器（多线程）

#### 设计思路

```
主线程：创建 TCP 和 UDP 套接字
    ↓
创建两个线程：
    ├─ TCP 处理线程
    └─ UDP 处理线程
```

#### 核心代码结构

```c
// 主线程
pthread_t tcp_thread, udp_thread;

pthread_create(&tcp_thread, NULL, tcp_server_main, NULL);
pthread_create(&udp_thread, NULL, udp_server_main, NULL);

pthread_join(tcp_thread, NULL);
pthread_join(udp_thread, NULL);
```

CC = gcc
CFLAGS = -Wall -Wextra -g
LDFLAGS = -lpthread

          $(BUILD_DIR)/udp_echo_server \
          $(BUILD_DIR)/tcp_echo_client \
          $(BUILD_DIR)/udp_echo_client

$(BUILD_DIR)/tcp_echo_server: $(SRC_DIR)/tcp_echo_server.c $(SRC_DIR)/common.h

	@mkdir -p $(BUILD_DIR)

	@mkdir -p $(BUILD_DIR)

	@mkdir -p $(BUILD_DIR)

	rm -rf $(BUILD_DIR)

.PHONY: all clean
