## 1. 线程基础概念

### 1.1 什么是线程
- **定义**：线程是进程中的一个执行单元，是进程中的一个实体，是CPU调度和分配的基本单位，是比进程更小的能独立运行的基本单位
- **特点**：
  - 同一进程内的线程共享内存空间
  - 线程间切换开销小
  - 线程间通信简单（共享内存）
  - 线程是轻量级的进程

### 1.2 线程与进程的区别
| 特性 | 进程 | 线程 |
|------|------|------|
| 内存空间 | 独立 | 共享 |
| 创建开销 | 大 | 小 |
| 通信方式 | IPC | 共享内存 |
| 切换开销 | 大 | 小 |
| 安全性 | 高 | 低 |

### 1.3 线程ID类型
```c
pthread_t pid;  // 线程ID，通常为 long int 类型
```

## 2. 线程创建与管理

### 2.1 线程创建函数

#### pthread_create()
```c
int pthread_create(pthread_t *thread, const pthread_attr_t *attr, 
                   void *(*start_routine) (void *), void *arg);
```

**参数说明**：
- `thread`: 线程ID指针，用于存储新创建的线程ID
- `attr`: 线程属性，通常设置为NULL使用默认属性
- `start_routine`: 线程函数指针，线程启动后执行的函数
- `arg`: 传递给线程函数的参数

**返回值**：
- 成功：返回0
- 失败：返回错误码

**使用示例**：
```c
pthread_t thread_id;
int thread_arg = 42;

void *thread_function(void *arg) {
    int value = *(int *)arg;
    printf("线程参数: %d\n", value);
    return NULL;
}

// 创建线程
if (pthread_create(&thread_id, NULL, thread_function, &thread_arg) != 0) {
    perror("pthread_create");
    exit(1);
}
```

### 2.2 线程等待函数

#### pthread_join()
```c
int pthread_join(pthread_t thread, void **retval);
```

**参数说明**：
- `thread`: 要等待的线程ID
- `retval`: 用于接收线程返回值的指针，如果不需要返回值可以设置为NULL

**功能**：
- 阻塞调用线程，直到指定的线程结束
- 类似于进程中的wait()函数
- 每个线程只能被join一次

**使用示例**：
```c
void *thread_function(void *arg) {
    // 线程工作
    return (void *)42;  // 返回一个值
}

pthread_t thread_id;
pthread_create(&thread_id, NULL, thread_function, NULL);

void *return_value;
pthread_join(thread_id, &return_value);
printf("线程返回值: %ld\n", (long)return_value);
```

### 2.3 线程分离

#### pthread_detach()
```c
int pthread_detach(pthread_t thread);
```

**功能**：
- 分离线程，使其成为分离状态
- 分离的线程结束后会自动回收资源
- 分离的线程不能被pthread_join()等待

**使用场景**：
- 不需要等待线程结束
- 不需要获取线程返回值
- 希望线程自动清理资源

**使用示例**：
```c
pthread_t thread_id;
pthread_create(&thread_id, NULL, thread_function, NULL);
pthread_detach(thread_id);  // 分离线程
// 主线程可以继续执行，不需要等待子线程
```

### 2.4 线程退出

#### pthread_exit()
```c
void pthread_exit(void *retval);
```

**功能**：
- 终止当前线程
- 可以传递返回值给pthread_join()

**使用示例**：
```c
void *thread_function(void *arg) {
    // 执行一些工作
    pthread_exit((void *)100);  // 退出并返回值
}
```

## 3. 线程同步机制

### 3.1 竞态条件问题

**问题描述**：
多个线程同时访问共享资源时，由于执行顺序的不确定性，可能导致结果不一致。

**示例**：
```c
int counter = 0;

void *increment(void *arg) {
    for (int i = 0; i < 10000; i++) {
        counter++;  // 非原子操作，可能产生竞态条件
    }
    return NULL;
}
```

### 3.2 互斥锁 (Mutex)

#### 3.2.1 互斥锁类型
```c
pthread_mutex_t mutex;
```

#### 3.2.2 互斥锁函数

**初始化互斥锁**：
```c
int pthread_mutex_init(pthread_mutex_t *mutex, const pthread_mutexattr_t *attr);
```
- `mutex`: 互斥锁指针
- `attr`: 互斥锁属性，通常为NULL
- 返回值：0成功，非0失败

**静态初始化**：
```c
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
```

**锁定互斥锁**：
```c
int pthread_mutex_lock(pthread_mutex_t *mutex);
```
- 阻塞式锁定，如果锁已被占用则等待

**尝试锁定互斥锁**：
```c
int pthread_mutex_trylock(pthread_mutex_t *mutex);
```
- 非阻塞式锁定，立即返回结果

**解锁互斥锁**：
```c
int pthread_mutex_unlock(pthread_mutex_t *mutex);
```

**销毁互斥锁**：
```c
int pthread_mutex_destroy(pthread_mutex_t *mutex);
```

**使用示例**：
```c
pthread_mutex_t counter_mutex = PTHREAD_MUTEX_INITIALIZER;
int counter = 0;

void *increment(void *arg) {
    for (int i = 0; i < 10000; i++) {
        pthread_mutex_lock(&counter_mutex);
        counter++;
        pthread_mutex_unlock(&counter_mutex);
    }
    return NULL;
}
```

### 3.3 读写锁 (Read-Write Lock)

#### 3.3.1 读写锁特点
- 允许多个线程同时读取共享资源
- 只允许一个线程写入共享资源
- 读操作可以并发，写操作独占

#### 3.3.2 读写锁函数

**初始化读写锁**：
```c
int pthread_rwlock_init(pthread_rwlock_t *rwlock, const pthread_rwlockattr_t *attr);
```

**静态初始化**：
```c
pthread_rwlock_t rwlock = PTHREAD_RWLOCK_INITIALIZER;
```

**读锁定**：
```c
int pthread_rwlock_rdlock(pthread_rwlock_t *rwlock);
```

**写锁定**：
```c
int pthread_rwlock_wrlock(pthread_rwlock_t *rwlock);
```

**解锁**：
```c
int pthread_rwlock_unlock(pthread_rwlock_t *rwlock);
```

**销毁读写锁**：
```c
int pthread_rwlock_destroy(pthread_rwlock_t *rwlock);
```

**使用示例**：
```c
pthread_rwlock_t rwlock = PTHREAD_RWLOCK_INITIALIZER;
int shared_data = 0;

void *reader(void *arg) {
    pthread_rwlock_rdlock(&rwlock);
    printf("读取数据: %d\n", shared_data);
    pthread_rwlock_unlock(&rwlock);
    return NULL;
}

void *writer(void *arg) {
    pthread_rwlock_wrlock(&rwlock);
    shared_data++;
    printf("写入数据: %d\n", shared_data);
    pthread_rwlock_unlock(&rwlock);
    return NULL;
}
```

### 3.4 自旋锁 (Spinlock)

#### 3.4.1 自旋锁特点
- 线程在等待锁时不会睡眠，而是不断检查锁的状态
- 适用于锁持有时间非常短的场景
- 在多核CPU上性能较好

#### 3.4.2 自旋锁函数

**初始化自旋锁**：
```c
int pthread_spin_init(pthread_spinlock_t *lock, int pshared);
```
- `pshared`: PTHREAD_PROCESS_PRIVATE（进程内）或PTHREAD_PROCESS_SHARED（进程间）

**锁定自旋锁**：
```c
int pthread_spin_lock(pthread_spinlock_t *lock);
```

**尝试锁定自旋锁**：
```c
int pthread_spin_trylock(pthread_spinlock_t *lock);
```

**解锁自旋锁**：
```c
int pthread_spin_unlock(pthread_spinlock_t *lock);
```

**销毁自旋锁**：
```c
int pthread_spin_destroy(pthread_spinlock_t *lock);
```

**使用示例**：
```c
pthread_spinlock_t spinlock;
int counter = 0;

void *spinlock_worker(void *arg) {
    for (int i = 0; i < 1000000; i++) {
        pthread_spin_lock(&spinlock);
        counter++;
        pthread_spin_unlock(&spinlock);
    }
    return NULL;
}
```

### 3.5 条件变量 (Condition Variable)

#### 3.5.1 条件变量概念
- 用于线程间的条件等待和通知
- 必须与互斥锁配合使用
- 允许线程等待某个条件成立

#### 3.5.2 条件变量函数

**初始化条件变量**：
```c
int pthread_cond_init(pthread_cond_t *cond, const pthread_condattr_t *attr);
```

**静态初始化**：
```c
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;
```

**等待条件变量**：
```c
int pthread_cond_wait(pthread_cond_t *cond, pthread_mutex_t *mutex);
```
- 原子地释放互斥锁并等待条件变量
- 被唤醒时重新获取互斥锁

**定时等待条件变量**：
```c
int pthread_cond_timedwait(pthread_cond_t *cond, pthread_mutex_t *mutex, 
                          const struct timespec *abstime);
```

**发送信号**：
```c
int pthread_cond_signal(pthread_cond_t *cond);
```
- 唤醒一个等待条件变量的线程

**广播信号**：
```c
int pthread_cond_broadcast(pthread_cond_t *cond);
```
- 唤醒所有等待条件变量的线程

**销毁条件变量**：
```c
int pthread_cond_destroy(pthread_cond_t *cond);
```

**生产者-消费者示例**：
```c
pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;
int buffer[5];
int count = 0;

void *producer(void *arg) {
    for (int i = 0; i < 10; i++) {
        pthread_mutex_lock(&mutex);
        while (count == 5) {
            pthread_cond_wait(&cond, &mutex);
        }
        buffer[count++] = i;
        printf("生产: %d\n", i);
        pthread_cond_signal(&cond);
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}

void *consumer(void *arg) {
    for (int i = 0; i < 10; i++) {
        pthread_mutex_lock(&mutex);
        while (count == 0) {
            pthread_cond_wait(&cond, &mutex);
        }
        int item = buffer[--count];
        printf("消费: %d\n", item);
        pthread_cond_signal(&cond);
        pthread_mutex_unlock(&mutex);
    }
    return NULL;
}
```

### 3.6 信号量 (Semaphore)

#### 3.6.1 信号量概念
- 用于控制对共享资源的访问
- 可以设置初始值
- 支持P操作（wait）和V操作（post）

#### 3.6.2 信号量函数

**初始化信号量**：
```c
int sem_init(sem_t *sem, int pshared, unsigned int value);
```
- `pshared`: 0表示进程内共享，非0表示进程间共享
- `value`: 信号量的初始值

**等待信号量**：
```c
int sem_wait(sem_t *sem);
```
- P操作，信号量值减1，如果值为0则阻塞

**尝试等待信号量**：
```c
int sem_trywait(sem_t *sem);
```
- 非阻塞版本的sem_wait

**发送信号量**：
```c
int sem_post(sem_t *sem);
```
- V操作，信号量值加1

**获取信号量值**：
```c
int sem_getvalue(sem_t *sem, int *sval);
```

**销毁信号量**：
```c
int sem_destroy(sem_t *sem);
```

**使用示例**：
```c
sem_t sem;
int shared_resource = 0;

void *worker(void *arg) {
    sem_wait(&sem);  // 获取信号量
    shared_resource++;
    printf("访问共享资源: %d\n", shared_resource);
    sem_post(&sem);  // 释放信号量
    return NULL;
}

int main() {
    sem_init(&sem, 0, 1);  // 初始值为1，表示只有一个资源
    
    pthread_t threads[5];
    for (int i = 0; i < 5; i++) {
        pthread_create(&threads[i], NULL, worker, NULL);
    }
    
    for (int i = 0; i < 5; i++) {
        pthread_join(threads[i], NULL);
    }
    
    sem_destroy(&sem);
    return 0;
}
```

## 4. 高级线程特性

### 4.1 线程取消

#### 4.1.1 线程取消类型

**延迟取消 (Deferred Cancellation)**：
- 默认取消类型
- 线程只能在取消点被取消
- 取消点包括：pthread_join, pthread_cond_wait, sem_wait等

**异步取消 (Asynchronous Cancellation)**：
- 线程可以在任何时候被取消
- 可能导致数据不一致

#### 4.1.2 线程取消函数

**取消线程**：
```c
int pthread_cancel(pthread_t thread);
```

**设置取消状态**：
```c
int pthread_setcancelstate(int state, int *oldstate);
```
- `state`: PTHREAD_CANCEL_ENABLE 或 PTHREAD_CANCEL_DISABLE

**设置取消类型**：
```c
int pthread_setcanceltype(int type, int *oldtype);
```
- `type`: PTHREAD_CANCEL_DEFERRED 或 PTHREAD_CANCEL_ASYNCHRONOUS

**测试取消点**：
```c
void pthread_testcancel(void);
```

**使用示例**：
```c
void *thread_func(void *arg) {
    printf("线程开始运行\n");
    
    // 设置取消状态为启用
    pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    
    for (int i = 0; i < 10; i++) {
        printf("工作 %d\n", i);
        sleep(1);
        
        // 手动设置取消点
        pthread_testcancel();
    }
    
    printf("线程正常结束\n");
    return NULL;
}

int main() {
    pthread_t thread;
    pthread_create(&thread, NULL, thread_func, NULL);
    
    sleep(3);
    pthread_cancel(thread);  // 取消线程
    
    void *result;
    pthread_join(thread, &result);
    
    if (result == PTHREAD_CANCELED) {
        printf("线程被取消\n");
    }
    
    return 0;
}
```

## 5. 实际应用示例

### 5.1 多线程累加示例
```c
#include "common.h"

#define THREAD_COUNT 4
#define ADD_COUNT 50000

int sum = 0;
pthread_mutex_t sum_mutex = PTHREAD_MUTEX_INITIALIZER;

void *add_thread_func(void *arg) {
    int thread_id = *(int *)arg;
    
    pthread_mutex_lock(&sum_mutex);
    printf("线程 %d 开始执行\n", thread_id);
    
    for (int i = 0; i < ADD_COUNT; i++) {
        sum++;
    }
    
    pthread_mutex_unlock(&sum_mutex);
    printf("线程 %d 执行完毕\n", thread_id);
    return NULL;
}

int main() {
    pthread_t threads[THREAD_COUNT];
    int thread_ids[THREAD_COUNT];
    
    printf("创建 %d 个线程，每个线程累加 %d 次\n", THREAD_COUNT, ADD_COUNT);
    
    for (int i = 0; i < THREAD_COUNT; i++) {
        thread_ids[i] = i + 1;
        pthread_create(&threads[i], NULL, add_thread_func, &thread_ids[i]);
    }
    
    for (int i = 0; i < THREAD_COUNT; i++) {
        pthread_join(threads[i], NULL);
    }
    
    printf("最终结果: %d\n", sum);
    printf("期望结果: %d\n", THREAD_COUNT * ADD_COUNT);
    
    return 0;
}
```

### 5.2 生产者-消费者模型
```c
#include "common.h"

#define BUFFER_SIZE 5
int buffer[BUFFER_SIZE];
int count = 0;
int should_exit = 0;

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t cond = PTHREAD_COND_INITIALIZER;

void *producer(void *arg) {
    int item = 0;
    while (!should_exit) {
        pthread_mutex_lock(&mutex);
        
        while (count == BUFFER_SIZE && !should_exit) {
            pthread_cond_wait(&cond, &mutex);
        }
        
        if (should_exit) {
            pthread_mutex_unlock(&mutex);
            break;
        }
        
        buffer[count++] = item++;
        printf("生产者: 生产物品 %d，缓冲区中有 %d 个物品\n", item-1, count);
        
        pthread_cond_signal(&cond);
        pthread_mutex_unlock(&mutex);
        sleep(1);
    }
    
    printf("生产者线程退出\n");
    return NULL;
}

void *consumer(void *arg) {
    while (!should_exit) {
        pthread_mutex_lock(&mutex);
        
        while (count == 0 && !should_exit) {
            pthread_cond_wait(&cond, &mutex);
        }
        
        if (should_exit) {
            pthread_mutex_unlock(&mutex);
            break;
        }
        
        int consumed_item = buffer[--count];
        printf("消费者: 消费物品 %d，缓冲区中有 %d 个物品\n", consumed_item, count);
        
        pthread_cond_signal(&cond);
        pthread_mutex_unlock(&mutex);
        sleep(2);
    }
    
    printf("消费者线程退出\n");
    return NULL;
}

int main() {
    pthread_t producer_thread, consumer_thread;
    
    pthread_create(&producer_thread, NULL, producer, NULL);
    pthread_create(&consumer_thread, NULL, consumer, NULL);
    
    sleep(10);
    should_exit = 1;
    
    pthread_cond_broadcast(&cond);
    
    pthread_join(producer_thread, NULL);
    pthread_join(consumer_thread, NULL);
    
    pthread_cond_destroy(&cond);
    pthread_mutex_destroy(&mutex);
    
    return 0;
}
```

### 5.3 读写锁示例
```c
#include "common.h"

pthread_rwlock_t rwlock = PTHREAD_RWLOCK_INITIALIZER;
int shared_data = 0;

void *reader(void *arg) {
    int thread_id = *(int *)arg;
    
    for (int i = 0; i < 5; i++) {
        pthread_rwlock_rdlock(&rwlock);
        printf("读者 %d: 读取数据 %d\n", thread_id, shared_data);
        pthread_rwlock_unlock(&rwlock);
        sleep(1);
    }
    
    return NULL;
}

void *writer(void *arg) {
    int thread_id = *(int *)arg;
    
    for (int i = 0; i < 3; i++) {
        pthread_rwlock_wrlock(&rwlock);
        shared_data++;
        printf("写者 %d: 写入数据 %d\n", thread_id, shared_data);
        pthread_rwlock_unlock(&rwlock);
        sleep(2);
    }
    
    return NULL;
}

int main() {
    pthread_t readers[3], writers[2];
    int reader_ids[3] = {1, 2, 3};
    int writer_ids[2] = {1, 2};
    
    // 创建读者线程
    for (int i = 0; i < 3; i++) {
        pthread_create(&readers[i], NULL, reader, &reader_ids[i]);
    }
    
    // 创建写者线程
    for (int i = 0; i < 2; i++) {
        pthread_create(&writers[i], NULL, writer, &writer_ids[i]);
    }
    
    // 等待所有线程结束
    for (int i = 0; i < 3; i++) {
        pthread_join(readers[i], NULL);
    }
    for (int i = 0; i < 2; i++) {
        pthread_join(writers[i], NULL);
    }
    
    pthread_rwlock_destroy(&rwlock);
    return 0;
}
```

## 6. 最佳实践与注意事项

### 6.1 线程安全编程原则

1. **避免竞态条件**：
   - 使用互斥锁保护共享资源
   - 确保临界区尽可能短

2. **死锁预防**：
   - 按固定顺序获取多个锁
   - 使用超时机制
   - 避免嵌套锁

3. **资源管理**：
   - 及时释放锁
   - 正确销毁同步对象
   - 避免资源泄漏

### 6.2 性能优化建议

1. **选择合适的同步机制**：
   - 短时间持有锁：使用自旋锁
   - 长时间持有锁：使用互斥锁
   - 读多写少：使用读写锁

2. **减少锁竞争**：
   - 缩小临界区范围
   - 使用无锁数据结构
   - 考虑线程本地存储

3. **避免过度同步**：
   - 只在必要时使用锁
   - 考虑原子操作
   - 使用条件变量减少轮询

### 6.3 常见错误与解决方案

1. **忘记释放锁**：
   ```c
   // 错误示例
   pthread_mutex_lock(&mutex);
   // 忘记解锁
   
   // 正确做法
   pthread_mutex_lock(&mutex);
   // 临界区代码
   pthread_mutex_unlock(&mutex);
   ```

2. **死锁问题**：
   ```c
   // 错误示例：不同顺序获取锁
   // 线程1: lock A, then lock B
   // 线程2: lock B, then lock A
   
   // 正确做法：统一顺序
   // 所有线程都按 A, B 的顺序获取锁
   ```

3. **条件变量使用错误**：
   ```c
   // 错误示例：没有使用while循环
   if (count == 0) {
       pthread_cond_wait(&cond, &mutex);
   }
   
   // 正确做法：使用while循环
   while (count == 0) {
       pthread_cond_wait(&cond, &mutex);
   }
   ```
