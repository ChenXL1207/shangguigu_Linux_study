## 1. 进程基础概念

### 1.1 什么是进程
进程是程序的一次执行过程，是系统进行资源分配和调度的基本单位。每个进程都有：
- **进程ID (PID)**：唯一标识一个进程
- **父进程ID (PPID)**：创建该进程的进程ID
- **进程状态**：运行态、就绪态、阻塞态、僵尸态

### 1.2 进程状态详解
```c
// 进程状态转换图
运行态(Running) ←→ 就绪态(Ready)
    ↓
阻塞态(Blocked) ←→ 僵尸态(Zombie)
```

**状态说明：**
- **运行态**：进程正在CPU上执行
- **就绪态**：进程准备好运行，等待CPU调度
- **阻塞态**：进程等待I/O操作或其他事件
- **僵尸态**：进程已退出，但父进程未回收资源

### 1.3 进程调度算法
1. **时间片轮转(Round Robin)**：每个进程分配固定时间片
2. **优先级调度**：根据进程优先级调度
3. **多级反馈队列**：动态调整进程优先级

## 2. 进程创建与终止

### 2.1 fork()函数 - 进程创建
```c
#include <unistd.h>
pid_t fork(void);
```

**功能：** 创建一个新的子进程
**返回值：**
- `> 0`：父进程中返回子进程PID
- `= 0`：子进程中返回0
- `< 0`：创建失败

**关键特点：**
- 子进程是父进程的完整副本
- 子进程从fork()返回处开始执行
- 父子进程有独立的地址空间

**示例代码分析：**
```c
// orphan_process_test.c 中的核心逻辑
pid_t pid = fork();
if(pid < 0){
    perror("fork");
    exit(1);
}else if(pid == 0){
    // 子进程代码
    char *new_name = "ergou";
    // 执行execve替换程序
}else{
    // 父进程代码
    printf("I am father process, my id is %d, my child process id is %d\n",getpid(),pid);
}
```

### 2.2 execve()函数 - 程序替换
```c
#include <unistd.h>
int execve(const char *pathname, char *const argv[], char *const envp[]);
```

**功能：** 用新程序替换当前进程
**参数：**
- `pathname`：新程序的路径
- `argv`：命令行参数数组
- `envp`：环境变量数组

**重要特性：**
- 不创建新进程，只替换当前进程
- 成功后不会返回（除非失败）
- 子进程的PID保持不变

### 2.3 孤儿进程与僵尸进程

**孤儿进程：**
- 父进程先于子进程退出
- 子进程被init进程(PID=1)收养
- init进程负责回收孤儿进程资源

**僵尸进程：**
- 子进程已退出，但父进程未调用wait/waitpid
- 占用系统资源，需要及时回收
- 通过wait/waitpid函数回收

## 3. 进程等待与资源回收

### 3.1 waitpid()函数详解
```c
#include <sys/wait.h>
pid_t waitpid(pid_t pid, int *wstatus, int options);
```

**参数说明：**
- `pid`：
  - `-1`：等待任意子进程
  - `>0`：等待指定PID的子进程
  - `0`：等待同进程组的子进程
  - `<-1`：等待进程组ID等于参数绝对值的所有子进程
- `wstatus`：存储子进程退出状态
- `options`：选项，通常为0（阻塞等待）

**状态解析宏：**
```c
// 正常退出
if(WIFEXITED(status)){
    int exit_code = WEXITSTATUS(status);
    printf("子进程正常退出，退出码：%d\n", exit_code);
}

// 异常退出
if(WIFSIGNALED(status)){
    int signal_num = WTERMSIG(status);
    printf("子进程异常退出，信号：%d\n", signal_num);
}
```

**waitpid_test.c 核心知识点：**
- 阻塞等待子进程退出
- 回收子进程资源，避免僵尸进程
- 解析子进程退出状态
- 进程状态转换的完整理解

## 4. 进程间通信(IPC)

### 4.1 管道通信(Pipe)

#### 4.1.1 无名管道
```c
#include <unistd.h>
int pipe(int pipefd[2]);
```

**特点：**
- 半双工通信（单向）
- 只能用于有亲缘关系的进程
- 本质是内核缓冲区，FIFO队列

**文件描述符：**
- `pipefd[0]`：读端
- `pipefd[1]`：写端

**unnamede_pipe_test.c 实现要点：**
```c
// 创建管道
if(pipe(pipefd) == -1){
    perror("new pipe error");
    exit(EXIT_FAILURE);
}

// 子进程：关闭写端，读取数据
close(pipefd[1]);
read(pipefd[0], buffer, sizeof(buffer));

// 父进程：关闭读端，写入数据
close(pipefd[0]);
write(pipefd[1], argv[1], strlen(argv[1]));
```

**重要原则：**
- 父子进程必须关闭不用的文件描述符
- 管道有大小限制，写满会阻塞
- 读端关闭后，写端会收到SIGPIPE信号

### 4.2 消息队列(Message Queue)

#### 4.2.1 消息队列API
```c
#include <mqueue.h>

// 创建/打开消息队列
mqd_t mq_open(const char *name, int oflag, mode_t mode, struct mq_attr *attr);

// 发送消息
int mq_send(mqd_t mqdes, const char *msg_ptr, size_t msg_len, unsigned int msg_prio);

// 接收消息
ssize_t mq_receive(mqd_t mqdes, char *msg_ptr, size_t msg_len, unsigned int *msg_prio);

// 关闭消息队列
int mq_close(mqd_t mqdes);

// 删除消息队列
int mq_unlink(const char *name);
```

#### 4.2.2 消息队列属性
```c
struct mq_attr {
    long mq_flags;    // 消息队列标志
    long mq_maxmsg;   // 最大消息数
    long mq_msgsize;  // 最大消息长度
    long mq_curmsgs;  // 当前消息数
};
```

#### 4.2.3 父子进程消息队列通信
**father_son_mq_test.c 实现要点：**
- 父进程发送消息，子进程接收消息
- 使用`mq_timedsend`和`mq_timedreceive`设置超时
- 消息队列在父子进程间共享

#### 4.2.4 生产者消费者模型
**product.c (生产者)：**
- 从标准输入读取数据
- 发送到消息队列
- 支持Ctrl+D退出

**consumer.c (消费者)：**
- 从消息队列接收数据
- 打印到标准输出
- 检测EOF信号退出

### 4.3 共享内存(Shared Memory)

#### 4.3.1 共享内存API
```c
#include <sys/mman.h>

// 创建共享内存
int shm_open(const char *name, int oflag, mode_t mode);

// 删除共享内存
int shm_unlink(const char *name);

// 设置共享内存大小
int ftruncate(int fd, off_t length);

// 内存映射
void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);

// 解除映射
int munmap(void *addr, size_t length);
```

#### 4.3.2 共享内存实现步骤
```c
// 1. 创建共享内存
fd = shm_open(shm_name, O_CREAT | O_RDWR, 0666);

// 2. 设置大小
ftruncate(fd, 1024);

// 3. 内存映射
shm_addr = mmap(NULL, 1024, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);

// 4. 使用共享内存
strcpy(shm_addr, "Hello, Shared Memory!");

// 5. 解除映射
munmap(shm_addr, 1024);

// 6. 删除共享内存
shm_unlink(shm_name);
```

**特点：**
- 最快的IPC方式
- 需要同步机制（如信号量）
- 多个进程可同时访问

## 5. 实际应用案例

### 5.1 编译系统分析
**makefile 关键特性：**
```makefile
# 自动发现源文件
SRCS = $(shell find $(SRC_DIR) -name '*.c')

# 模式替换生成目标文件
OBJS = $(patsubst $(SRC_DIR)/%.c,$(BUILD_DIR)/%.o,$(SRCS))
TARGETS = $(patsubst $(SRC_DIR)/%.c,$(BUILD_DIR)/%.out,$(SRCS))

# 特殊链接规则
$(BUILD_DIR)/shared_memory.out: $(SRC_DIR)/shared_memory.c
	$(CC) $(CFLAGS) -o $@ $< -lrt
```

**编译要点：**
- 消息队列和共享内存需要链接`-lrt`库
- 自动依赖关系生成
- 并行编译支持

### 5.2 进程间通信选择指南

| 通信方式 | 适用场景 | 优点 | 缺点 |
|---------|---------|------|------|
| 管道 | 父子进程简单通信 | 简单易用 | 半双工，有亲缘关系限制 |
| 消息队列 | 异步通信，多进程 | 支持优先级，异步 | 有大小限制 |
| 共享内存 | 大数据量，高性能 | 速度最快 | 需要同步机制 |

## 6. 总结与复习要点

### 6.1 核心概念记忆
1. **进程创建**：fork()创建子进程，execve()替换程序
2. **进程等待**：waitpid()回收子进程资源，避免僵尸进程
3. **进程状态**：运行态→就绪态→阻塞态→僵尸态
4. **IPC方式**：管道、消息队列、共享内存

### 6.2 重要函数总结
```c
// 进程管理
pid_t fork(void);                    // 创建子进程
int execve(const char *pathname, char *const argv[], char *const envp[]);
pid_t waitpid(pid_t pid, int *wstatus, int options);

// 管道通信
int pipe(int pipefd[2]);

// 消息队列
mqd_t mq_open(const char *name, int oflag, mode_t mode, struct mq_attr *attr);
int mq_send(mqd_t mqdes, const char *msg_ptr, size_t msg_len, unsigned int msg_prio);
ssize_t mq_receive(mqd_t mqdes, char *msg_ptr, size_t msg_len, unsigned int *msg_prio);

// 共享内存
int shm_open(const char *name, int oflag, mode_t mode);
void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);
```

### 6.3 常见错误与调试
1. **忘记关闭文件描述符**：导致资源泄漏
2. **不回收子进程**：产生僵尸进程
3. **管道使用错误**：父子进程都读写同一端
4. **消息队列权限**：创建时权限设置错误
5. **共享内存同步**：多进程访问需要同步机制
